## Coding practice submissions

Solutions synchronized by the Code-to-GitHub Chrome extension:

- [HackerRank](./HackerRank/)
- [HackerEarth](./HackerEarth/)
- [LeetCode](./LeetCode/)

Each platform folder is organized by programming language and sanitized problem name. Each problem contains a README with available statement and submission metadata, a latest solution, and a `submissions/` folder retaining individual submission history.
